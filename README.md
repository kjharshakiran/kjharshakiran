## 📈 Trading & quantitative tools

| Project | What it does | Stack |
|---|---|---|
| [**TradeCompass**](https://github.com/kjharshakiran/tradecompass) | AI-assisted equity & crypto analytics: multi-source market data (Finnhub, Alpha Vantage), technical + fundamental screens, options flow, regime detection (Markov), Monte Carlo, LLM-generated strategies, backtesting, and autopilot daemons for equities and crypto. | Python · Streamlit · pandas · LLM APIs |
| [**edgedesk**](https://github.com/kjharshakiran/edgedesk) | An evidence engine for discretionary traders. Ships with an offline self-test on a synthetic market. | Python · Streamlit · NumPy · SQLite |
